Real-time 3D object detection system based on YOLOv5, targeting RK3588 (aarch64) + Orbbec Gemini 336 camera.
Detects knobs and indicator lights on operation panels, outputs 3D coordinates and panel surface normals.

**Why:** Industrial/embedded vision application for panel inspection/interaction.

**How to apply:** Local dev is on macOS (read/edit only, no hardware). Target platform is RK3588 Linux aarch64.
